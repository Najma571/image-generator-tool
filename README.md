# AI Image Generator

Powered by Replicate + Netlify Functions

## Folder Structure
```
image-generator-tool/
├── index.html
├── netlify.toml
└── netlify/
    └── functions/
        └── generate.js
```

## Deploy Steps
1. Upload this folder to GitHub
2. Connect to Netlify
3. Add environment variable: REPLICATE_API_TOKEN = your token
4. Deploy!
